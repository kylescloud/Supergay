## 🚀 Quick Start

For users who want to get started immediately:

1. **Clone repository**:
   ```bash
   git clone https://github.com/kylescloud/Supergay.git
   cd Supergay
   git checkout SupergayV2
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure environment**:
   ```bash
   cp .env.example .env
   nano .env
   ```

4. **Deploy contract**:
   ```bash
   npm run compile
   npx hardhat run scripts/deploy-flash-loan-contract.ts --network base
   ```

5. **Start bot**:
   ```bash
   npm run automated-executor
   ```

For complete instructions, see **PRODUCTION_MAINNET_DEPLOYMENT_GUIDE.md**.
